# 验证范围与兼容性记录

## 验证基线

当前实现使用一份 WPS 制作的 31 页、16:9 英语课件，在 macOS Apple Silicon 上对照 PowerPoint 与希沃白板验证。真实课件、截图和客户端分析副本留在本地，不包含在源码仓库中。

自动化测试通过不代表任何 PPTX 都能完整转换。当前的字体、行距和动画映射需要更多样本扩展；换一台机器时，还需要检查字体可用性。

## 已确认的关键行为

| 问题 | 原因与处理 | 验证方式 |
|---|---|---|
| 文字整体偏移 | 希沃 Text 自带 10 px 内边距，默认不额外平移文本框 | 元素几何对账、PowerPoint/希沃截图 |
| 叠加文字重影 | 渲染器字宽不同；将彩色覆盖文字重建为整行，非覆盖部分透明 | 同句黑字/彩色字叠加检查 |
| 图片延迟加载 404 | 缺少显式 ZIP 目录条目；先写 `Slides/`、`Resources/` | 只改变目录条目的对照实验、资源 HTTP 200、重新导入 |
| 表格边框偏短 | 保存的初始行高低于文字所需高度；按内容撑高并保持总高一致 | PowerPoint 实际行高读取、希沃编辑态检查 |
| 中文长列表溢出 | Kaiti SC 和 Latin 混排的基线/行距模型不同 | 长列表逐页对照及放映检查 |
| 临界换行差异 | 缩进 px/EMU 单位混用，以及行尾标点悬挂 | 缩进回归测试、PowerPoint 实际 line 内容与宽度 |
| 标题字体替代 | Office 私有字体不一定对其他应用可用 | 系统字体查询、安装本机字体后重启复测 |

### 动画检查

- 第 23 页：播放 8 个点击步骤，观察三个标签沿路径移动。
- 第 24 页：播放 11 个点击步骤，检查表格、答案和底部摘录依次出现。

## U8 听说课复测（0.1.2）

在 macOS Apple Silicon 上用 Microsoft PowerPoint 打开 18 页 U8 原稿，用希沃白板分别打开旧版与 0.1.2 输出。两侧窗口截图按画布边界裁切并等比例归一至 1440 × 810，逐页核对页码。仅按画布对齐，未对文字或形状进行局部配准。

边缘匹配 F1 取横纵相邻灰度差至少 32 的像素，使用 2 px 的切比雪夫距离容差，双向匹配后逐页等权平均。18 页平均从 87.63 提升至 93.95。第 5、13、14、16 页分别从 79.32、81.43、79.57、70.16 提升至 92.48、95.91、97.13、94.87。分数衡量内容边缘的位置，颜色、音频和动画需单独检查。

- 处理垂直居中文本的内边距与多行高度。支持符合条件的单段拉丁文字按词两端对齐，保留文本组的动画。第 13 页在两个应用核对开场、首次与第十次点击，答案随遮挡框消失而揭示。
- 支持无样式表格的网格与无网格预设，单元格显式线条优先。第 16 页恢复七行表格的内外边框。
- 第 7、8 页改为内嵌音频，保留两份原始 MP3。希沃授课模式实测播放启动和进度，总时长分别为 2:20 和 2:07。
- U7 的 31 页逐页做结构回归，对齐改动影响第 28 页。该页已在希沃复开，并与此前保留的 PowerPoint 截图对照。

本机交互式叠图为 `verification/u8/叠图对照.html`。第 2 页图文卡片仍有阴影和标题字宽差异。当前字间距处理覆盖单段、同字号、水平拉丁正文，复杂混排与不同字体环境仍需实机复测。

## 通用样式与同页叠图（0.1.3）

两份从空白生成的课件复用了一个自定义表格样式 ID。两份分别采用 4:3 和 16:9，使用不同的主题色、段落字号、单元格边距和图片阴影角度。PowerPoint 与希沃实机对照确认了主题表头、交替底色、显式单元格填充和阴影方向。单元格细线的深浅仍有差别。多母版主题解析另有合成单元测试。

U8 全部 18 页以 0.1.2 为基线，逐页等权平均边缘 F1 从 93.95 提高到 95.58。第 2 页从 81.73 提高到 93.26，第 3 页从 89.06 提高到 94.80，第 4 页从 88.02 提高到 94.73。U7 全部 31 页做结构回归，输出有变化的四页另行实机截图。第 8、15、24、25 页的 F1 分别为 96.11 → 96.11、83.42 → 84.28、91.51 → 91.47、80.35 → 80.35。这轮复测覆盖编辑画布，动画与音频的最近一次播放记录见上节。

### 在其他课件上复测

分别从 PowerPoint、旧版希沃输出和新版希沃输出截取同页画布。只裁画布四边，保留全部对象的相对位置。三组图片各放入一个目录，按 `p1.png`、`p2.png` 命名并保持页码集合一致。安装 `uv` 后执行：

```sh
mise run compare -- 原稿截图 旧版截图 新版截图 -o 对照报告.html
```

报告与图片保留相对路径，可切换页码、版本和透明度。工具按每页原始比例缩放至 1440 像素宽，取相邻灰度差至少 32 的边缘，以横纵 2 像素容差计算双向 F1。纯色对纯色记为无边缘。4:3 样例的 ENBX 画布保存为 960 × 720。实测 Mac 希沃会沿用此前选过的显示比例，截图前需核对右下角的 4:3 或 16:9。

普通不透明矩形的外阴影以独立透明图片保存，与可编辑矩形和文字共用原动画组。带透视、缩放或倾斜的外阴影以及其他几何形状的外阴影尚未覆盖。自定义表格样式当前支持实色填充与显式线条。只引用内置样式且未内嵌定义时仍受内置样式覆盖范围限制。

## 自动化检查

从仓库根目录运行：

```bash
mise run test
mise run vet
mise run cli
mise run app
```

测试包含合成 PPTX 的几何与结构检查、输入修补、预设形状、ENBX 转换、显式 ZIP 目录、表格撑高、字体行距、标点悬挂、段落缩进及 GUI 拖入流程。GUI 测试首轮会扫描系统字体，允许最多 30 秒完成异步任务。

首次在其他环境运行时，GUI 框架或系统字体可能带来平台差异；当前完整验证平台是 macOS Apple Silicon。

## 实机复测步骤

1. 用明确的 `-o` 路径生成候选，保留原课件与已验证版本。
2. 检查转换警告、ZIP 完整性、31 页等预期页数以及资源引用。
3. 在目标电脑的希沃白板打开候选。打开可能同步云端，应在操作前明确账号和同步范围。
4. 截图前核验当前页码，不能假定快速连续按键都已完成翻页。
5. 将 PowerPoint 与希沃的画布裁成相同比例，逐页比较文字、换行、标注、图片、表格和边界。
6. 在授课模式播放重点动画。编辑态重叠可能来自原稿的动画设计，不一定是转换错误。
7. 重启或重新导入后再次检查图片，避免只验证了首次加载时的内存预览。

## 尚未消除的差异

- 英文宽度、字距及两端对齐的空格分配仍可能不同。
- 多行、中英文混排的局部高亮，边缘与高度尚未完全统一。
- 复杂纵向合并、同段不同字号及其他字体需要更多实际样本。
- 未支持的图表、SmartArt、自定义几何、组合旋转/翻转或动画无法完整还原。
- 希沃授课工具栏可能覆盖贴底内容，需要与真正的文字截断区分。
